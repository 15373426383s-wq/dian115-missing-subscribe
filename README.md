# 缺集自动订阅 (missing-subscribe)

DIAN115 插件：读取宿主缺集扫描结果，按规则自动创建或合并聚合订阅。

- **规则**：从上到下逐季匹配；可按实例、媒体库、连载状态、最新季、缺集数/比例、年份、类型、地区、片名和 TMDB 名单筛选。
- **动作**：自动订阅、进待审、忽略；支持观察期、单轮上限、资源来源。
- **触发**：每小时一次 + 宿主缺集扫描完成后；自动运行默认关闭。
- **保护**：提交前用 Emby 实时结果复核；不改动手动创建的订阅；失败订阅冷却后重试。
- **通知**：结果按渠道推送；有待审项时 Telegram 带"全部批准 / 全部忽略"按钮。

## 页面

总览 / 规则 / 订阅（进行中、已补齐，支持清除记录）/ 审核 / 记录。

## 安装

经 MCP `dian115_compile_plugin` 编译出 `.dian115p` 正式包，在 DIAN115 插件中心上传安装。
